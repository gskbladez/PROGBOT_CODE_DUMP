# Privacy Policy

Last revised on July 27, 2026.

This Privacy Policy explains what information ProgBot collects and how it is used.

## Information Collected

ProgBot may store information logged by the discord.py API. This includes:

* Discord user IDs
* Discord user names
* Discord server IDs
* Discord channel IDs
* Discord role IDs
* Discord user nicknames on servers from which ProgBot commands are given
* Discord user join dates of the servers from which ProgBot commands are given

None of this information can personally identify a specific user to this app. 

## How Information Is Used

Collected information is used solely to:

* Provide bot features
* Improve reliability and performance

## Data Sharing

ProgBot does share user data with third parties. 

## Data Retention

Data may be retained as long as necessary to operate the bot and its features.

## Data Removal

Users may request the removal of their stored data by contacting the developer.

## Links to Third Party Websites

ProgBot contains links to third-party websites. We are not responsible for the privacy policies on these websites, which may differ from our own.

## Changes

These terms may be updated at any time. Continued use of ProgBot after changes constitutes acceptance of the updated terms.

## Contact

For privacy-related questions or data removal requests, contact the developers through the ProgBot GitHub repository or over Discord. (You can use `bugreport` to send a message to the developer's channel.)
